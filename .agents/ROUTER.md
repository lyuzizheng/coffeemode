# Agent Router

Choose the workflow by intent, not by keyword matching.

| Intent | Workflow |
| --- | --- |
| Implement, build, fix, 实现, 修复 | [development-cycle](./workflows/development-cycle.md) |
| Review, audit, 审查, 评估 | [review-code](./workflows/review-code.md) |
| Design, UI, visual, 设计, 界面 | [refine-ui](./workflows/refine-ui.md) |
| Test, QA, 测试 | [testing](./workflows/testing.md) |
| Grill, align, stress-test, 对齐, 拷问 | [design-grill](./workflows/design-grill.md) |
| Orientation, status, plan, 进度 | [development-cycle](./workflows/development-cycle.md) |

For mixed intents, resolve the earliest blocker first. Unknown intent defaults to orientation, never implementation.
