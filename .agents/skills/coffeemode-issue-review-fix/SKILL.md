# CoffeeMode Issue Review and Fix

Start at the verify-and-scope step in `.agents/workflows/closed-loop.md` and apply
`.agents/rules/issues.md`. The issue is a hypothesis: reproduce it, fix the shared
root cause, sweep sibling sites, and keep unrelated findings in linked issues.
